연산 우선순위

완료 안정성은 항상 최우선입니다. 나머지 기준은 위아래 버튼으로 조정하며 모델 선택, 추론 강도, 한도 소진 시 대체 순서에 적용합니다.

결과 품질이나 추론량을 앞에 두면 모델이 지원하는 높은 추론 강도를 사용합니다. 토큰과 속도 우선으로 바꾸면 불필요하게 높은 강도를 피합니다. 자동 모델 비교는 실행 초기에 판정 모델을 추가 호출해 토큰과 시간이 더 들 수 있습니다.

자동 역할은 판정 모델이 작업·후보 정보·잔여 한도·위 우선순위를 보고 주 모델과 대체 순서를 함께 판단합니다. 직접 지정한 역할은 유지합니다. 모델별 성능 실측이 없으면 추측으로 점수를 만들지 않습니다.

작업 환경 자동 구성
연결된 프로젝트가 없으면 새 프로젝트를 만듭니다. 계획 모델은 폴더 이름과 검증 방법을 제안하고, 판정 모델은 제안·검증·최종 결과를 독립적으로 판단합니다. Jev를 선택하면 모든 판정에서 Jev를 먼저 사용합니다.

Loop에서 사용할 MCP 도구

자동 사용 연결은 매 실행에 포함됩니다. 그 외 연결은 여기서 선택할 수 있습니다. Jev 판정 연결에는 도구를 보내지 않습니다.

연결된 MCP 도구가 없습니다.

작업을 보내면 계획 → 파일 작업 → 검증 → 판정을 자동으로 이어갑니다. 확인 가능한 잔여 한도와 토큰 사용량을 기록합니다. 잔여 한도 정보가 없는 연결은 한도 초과 응답을 받으면 저장된 다음 모델로 전환합니다. 중지 버튼으로 언제든 멈출 수 있습니다.
