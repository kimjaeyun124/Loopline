# Loopline

목표 설정 → 실행 → 검토 → 개선을 이어가는 루프 엔지니어링용 AI 작업 공간입니다. 원하는 Codex·Claude Code·API 연결을 직접 추가하고, ChatGPT·Gemini 공식 웹 대화도 필요한 경우에만 작업 공간에 표시합니다. 일반 작업은 자동 반복하지 않으며, 모델 선택 메뉴에서 **Loop Engineering**을 선택하면 반복 실행을 시작할 수 있습니다.

ChatGPT Desktop처럼 채팅을 중심으로 화면을 구성한 macOS 데스크톱 앱입니다. 새 설치에서는 AI 연결이 비어 있으며, 설정에서 필요한 서비스만 추가합니다. 상단에서 추가한 Codex·Claude Code·API 연결을 선택하고, 입력창 하단에서 해당 연결의 세부 모델을 선택합니다. 여러 Codex 계정을 연결하고 계정별 남은 사용량을 확인할 수 있으며, Codex 사용 한도 소진 시 남은 계정으로 요청을 다시 시도합니다. 대화 내용은 앱 창의 `localStorage`에 저장되고, Codex 대화는 연결된 계정의 Codex thread 기록에도 저장됩니다. OpenAI·Anthropic·Google의 공식 앱은 아닙니다.

## 연결과 모델 선택

처음 사용해 저장된 선택이 없으면 상단에 **모델 추가**가 표시됩니다. **설정 → AI 연결 → AI 추가**에서 Codex·Claude Code·ChatGPT·Gemini·API 에이전트 중 원하는 항목을 고를 수 있습니다. Codex·Claude Code를 추가하면 해당 CLI 로그인 흐름을 시작하고, API 에이전트는 주소와 키를 입력해 모델을 가져옵니다. ChatGPT·Gemini는 공식 웹 화면을 추가한 뒤 계정으로 로그인합니다. Codex·Claude Code·ChatGPT·Gemini를 Loopline에서 삭제해도 CLI 또는 웹사이트 로그인은 유지됩니다. 연결을 고른 뒤 입력창의 **모델 선택**에서 세부 모델을 고릅니다.

모델을 선택하기 전에는 메시지를 전송하지 않습니다. 다른 연결로 바꾸면 세부 모델 선택이 비워지고, 기존 입력은 유지됩니다. 저장된 선택과 기존 대화의 모델은 복원하며, 연결 상태를 새로고침해도 빈 모델을 자동 선택하지 않습니다. **표시 설정**에서 숨긴 모델은 세부 모델 목록에서도 숨겨집니다.

## Loop Engineering 실행

상단 **연결 선택 → Loop Engineering**을 선택하면 **Harness**로 실행합니다. **구성**에서는 계획·구현·판정 모델과 Effort만 지정합니다. 연결된 프로젝트 폴더가 있으면 사용하고, 없으면 판정 모델이 폴더 이름을 정해 앱 데이터의 `harness/projects` 안에 새 Git 프로젝트를 만듭니다. 같은 대화는 이 프로젝트를 계속 사용합니다. 일반 연결을 선택하면 Loop 모드가 해제됩니다. 한 번 시작하면 **계획 → 파일 작업 → 검증 → 판정 → 다음 회차**를 승인 창 없이 진행합니다. 검증과 판정이 모두 통과하면 변경을 원본에 자동 반영합니다. 자동 반영을 끄면 검토된 작업 공간과 패치만 보관합니다.

- **모든 연결에 공통 적용:** Codex·Claude Code·OpenAI 호환 텍스트 API가 같은 파일 도구를 사용합니다. 모델이 JSON으로 읽기·목록·쓰기·정확한 치환·삭제를 요청하면 Harness가 별도 작업 공간에서 실행합니다. 기본 CLI 권한은 확장하지 않습니다.
- **역할과 Effort:** 구현은 선택한 모델, 계획은 지원하는 추론 강도를 기준으로 자동 배정합니다. 각 역할은 직접 변경할 수 있습니다. API 모델은 `/models`의 `supported_reasoning_efforts`가 제공된 경우에만 강도를 전달하며, 목록이 없으면 서비스 기본값을 씁니다.
- **구성 자동 저장:** 모델·Effort·자동 반영 옵션은 변경 즉시 저장되며 새 작업과 앱 재실행에도 유지됩니다. 작업 폴더와 검증 명령을 수동으로 입력할 필요가 없습니다. 판정 모델이 프로젝트 파일을 확인해 첫 회차 전에 오프라인 검증 명령과 근거를 결정합니다. 일반적인 테스트 실패 뒤에도 같은 명령을 유지해 회차마다 같은 기준으로 판정하며, 명령 실행 자체가 불가능한 경우에만 다른 명령을 다시 선택합니다. 읽기 요청은 최대 8회로 제한되며, 준비 실패 시 원본에는 반영하지 않습니다. 기존 API의 명시적 검증 명령은 호환성을 위해 계속 지원합니다.
- **Jev 판정:** 연결한 모델 ID·이름·연결 이름에서 Jev를 찾아 기본 판정 모델로 지정합니다. 실제 Jev를 사용하려면 기존 API 에이전트에서 해당 서비스의 OpenAI 호환 주소와 인증 정보를 먼저 연결해야 합니다. 전용 Jev 인증 방식은 구현하지 않았으며, Jev가 없으면 판정 모델을 직접 선택해야 합니다.
- **자동 회차와 중지:** 기본 자동 모드는 작업 난도에 따라 4회 또는 6회부터 시작합니다. 판정에서 수정이 필요하다고 하면 두 회씩 최대 10회까지 늘리고, 완료 판정이 통과되면 바로 끝냅니다. 실제 변경 패치가 두 차례 연속 같으면 판정 피드백으로 계획을 다시 세우고, 저장된 구현 대체 모델이 있으면 다음 모델로 전환합니다. 진행이 계속 없고 쓸 대체 모델도 없으면 미완료 패치를 원본에 반영하지 않고 안전 종료합니다. 수동 회차는 2~10회에서 지정할 수 있습니다. 한 회차의 파일 도구 요청은 최대 16번이며, 같은 읽기 요청이 세 번 연속 반복되면 중단합니다. 중지를 누르면 현재 모델 요청·검증 명령과 다음 회차를 취소합니다. 이미 시작한 원본 패치 반영은 일관성을 위해 완료 결과를 기다립니다.
- **기존 변경 보호:** 원본의 미커밋 변경을 별도 Git 작업 공간에 복사해 시작합니다. 실행 중 원본 내용이 바뀌면 자동 반영을 중단하고 패치를 남깁니다. 사용자 index와 기존 커밋은 수정하지 않습니다. 서브모듈·심볼릭 링크 파일 작업은 지원하지 않습니다.
- **검증:** 현재 macOS의 격리 실행을 사용합니다. 판정 모델이 결정한 검증 명령을 실행하고 네트워크와 작업 공간 밖 쓰기를 차단합니다. `node_modules`와 다른 ignored 파일은 복사하지 않으므로 판정 모델은 오프라인에서 실행 가능한 검증을 구성해야 합니다. 검증 실패를 모델의 완료 판정으로 덮어쓸 수 없습니다.
- **지침·기록:** 설정의 제공자별 지침, 프로젝트 지침, 루트 `AGENTS.md`·`CLAUDE.md`를 전달합니다. 단계와 실제 파일 작업·검증 결과·판정을 한영 제목으로 `Worked for`에 표시하며, 내부 추론 전문은 표시하지 않습니다. 각 모델 호출의 제공된 토큰 사용량을 기존 통계에 기록합니다.
- **복구:** 새로고침하면 실행 상태를 다시 조회합니다. 앱 종료로 중단된 작업은 자동 재실행하지 않습니다. 사용자 데이터 폴더의 `harness`에 실행 기록·작업 공간·패치를 보관합니다. 현재 자동 정리는 하지 않습니다.

**모델 반복**을 선택하면 이전 방식처럼 한 모델의 응답을 이어서 개선합니다. 이 모드는 실제 파일 변경을 제공하는 Harness와 별개입니다. 모든 모드에서 반복 호출마다 서비스 사용량이 추가됩니다. 앱 자체는 실행마다 승인 창을 띄우지 않지만 최초 계정 로그인이나 macOS의 폴더 접근 권한은 운영체제·서비스 정책을 따릅니다.

### Harness QA

`node --test tests/*.test.mjs`로 임시 Git 프로젝트와 로컬 API 모형을 사용해 반복·중지·자동 반영·충돌·검증·사용량 기록을 확인합니다. 실제 모델 호출이나 사용자 프로젝트 변경은 없습니다. `node tests/fixtures/harness-server.mjs --visible`은 화면 QA용 주소와 프로젝트 경로를 출력합니다. 테스트 연결 이름에는 **시뮬레이션**을 표시하며, 실제 Jev 성능이나 모델별 응답 품질을 검증한 결과는 아닙니다.

2026-09-29 QA: 자동 검사 16개 통과. 실제 `gpt-6-luna`를 계획·구현·판정 역할에 지정한 별도 임시 프로젝트에서 파일 읽기 → 수정 → 검증 → 판정 → 자동 반영을 확인했습니다. 실제 실행 중 중지와 새로고침 복구도 확인했습니다. Jev·Claude의 실제 호출은 이번 QA에 포함하지 않았습니다.

## 계정 메뉴와 Usage

사이드바 하단의 계정 이름을 누르면 **Usage**와 **Settings** 메뉴가 열립니다. **Usage** 옆에는 현재 선택한 Codex 계정의 기간별 한도 중 가장 적게 남은 비율을 표시합니다. Usage 상단의 **남은 사용 한도 → 조회 계정**은 기본으로 **전체 계정**을 표시하며, 원하는 계정을 선택하면 해당 계정의 한도만 볼 수 있습니다. 각 Codex 계정의 기간별 잔여 비율과 초기화 시간을 표시하고, 정확한 잔여 토큰 수는 제공되지 않습니다. 조회 계정 선택은 대화에 사용하는 계정이나 아래 활동 통계의 계정을 바꾸지 않습니다. 새로고침 후에도 조회 선택을 유지하며, 선택한 연결을 삭제하면 전체 계정으로 돌아갑니다. 조회에 실패하면 마지막 조회 시각과 함께 표시합니다.

Claude Code 사용량은 CLI의 `/usage`로, API 연결의 사용량·잔액은 해당 서비스 대시보드에서 확인합니다. **Settings**는 기존 계정·모델·대화·화면 설정을 엽니다. 계정 메뉴는 방향키로 이동하고 Escape 또는 바깥 클릭으로 닫을 수 있습니다.

## 화면 테마

**계정 메뉴 → Settings → 화면**에서 라이트·다크·시스템을 선택합니다. 기본값인 시스템은 macOS 또는 브라우저의 화면 모드를 따르며, 설정을 바꾸면 대화창·사이드바·입력창·모델 목록·설정과 팝업에 바로 반영됩니다. 선택은 이 앱 또는 브라우저의 로컬 저장소에 보관되어 다음 실행에도 유지됩니다.

macOS 앱에서는 네이티브 메뉴와 창에도 선택한 테마를 적용하고, 내부 웹 화면에 같은 색상 모드를 전달합니다. ChatGPT 웹에서 라이트·다크를 따로 지정한 경우 웹 설정이 우선하며, ChatGPT 상단 바는 웹 화면의 표시 테마에 맞춰집니다. 감지할 수 없는 화면에서는 앱 테마를 사용합니다. 함께 전환하려면 ChatGPT의 화면 설정을 **시스템**으로 선택하세요.

## ChatGPT 사용

**설정 → AI 연결 → AI 추가 → ChatGPT**를 선택해 추가한 뒤, 상단의 **ChatGPT** 또는 **Settings → AI 연결 → 열기**를 선택합니다. macOS 앱에서는 Loopline 메인 창 안에 ChatGPT가 표시되고, 웹 개발 화면에서는 새 브라우저 탭으로 열립니다. [ChatGPT 공식 웹](https://learn.chatgpt.com/docs/web)에 직접 로그인한 뒤 해당 계정에서 제공하는 모델·대화·프로젝트를 사용합니다. API 키를 입력할 필요가 없습니다.

내부 화면은 `chatgpt.com`을 그대로 표시합니다. Codex 로그인과 별도의 세션(`persist:loopline-chatgpt`)에 로그인 쿠키를 보관하며, 이전 ChatGPT 전용 창의 세션도 이어 사용합니다. Loopline은 로그인 비밀번호·쿠키를 읽거나 다른 계정에 복사하지 않습니다. ChatGPT 대화가 Loopline의 로컬 대화 목록에 자동으로 복사되지는 않습니다. 필요한 기록은 **설정 → 대화 가져오기**에서 내보내기 파일로 가져올 수 있습니다.

상단 중앙의 전환 메뉴에서 **작업 공간 / ChatGPT / Gemini**를 선택합니다. 웹 대화를 사용할 때는 Loopline 사이드바를 숨겨 서비스의 사이드바 하나만 표시합니다. 높이 48px의 상단 바는 공식 화면의 배경색을 따르며 선택한 탭만 강조합니다. **작업 공간**을 누르면 기존 입력과 사이드바 상태로 돌아갑니다. 화면을 전환해도 각 웹 페이지와 작성 중인 Loopline 입력은 유지됩니다. 뒤로·앞으로·새로고침은 왼쪽에, 사이트 도메인·브라우저에서 열기·설정은 오른쪽에 표시합니다. macOS **대화** 메뉴에서도 같은 동작과 ChatGPT 열기 단축키(`⌘⇧G`)를 제공합니다. 설정이나 검색 창을 열면 웹 대화 화면을 잠시 가려 해당 창을 사용할 수 있습니다. 연결 실패 화면에는 다시 시도와 브라우저 열기 버튼을 제공합니다.

로그인 과정에서 인증 팝업이 열릴 수 있습니다. ChatGPT의 외부 링크는 확인 후 기본 브라우저에서 열립니다. 로그인 제공업체나 서비스의 브라우저 정책으로 앱에서 진행할 수 없는 경우 **브라우저에서 열기**를 사용하세요. 이 동작은 브라우저의 별도 로그인 세션을 사용합니다.

마이크·카메라는 ChatGPT의 요청에 사용자가 허용한 경우에만 사용할 수 있으며 macOS 권한도 필요합니다. 화면 공유 등 앱 내부 화면이 지원하지 않는 권한이 필요한 기능은 브라우저에서 사용하세요. 이 연결은 공식 웹 화면을 제공하는 방식이며, 모든 ChatGPT 기능의 앱 내부 호환성을 보장하지 않습니다.

## Gemini 사용

**설정 → AI 연결 → AI 추가 → Gemini**를 선택해 추가한 뒤, 상단의 **Gemini** 또는 **Settings → AI 연결 → 열기**를 선택합니다. macOS 앱 안에서 `gemini.google.com/app`을 열며, Google 계정으로 직접 로그인하여 대화합니다. API 키는 필요하지 않습니다. macOS **대화 → Gemini 열기** 단축키는 `⌘⇧M`입니다. 웹 개발 화면에서는 공식 사이트를 새 브라우저 탭으로 엽니다.

Gemini는 `persist:loopline-gemini` 세션을 사용해 ChatGPT와 로그인 정보를 분리합니다. 화면 전환은 페이지를 숨기거나 다시 표시하므로 앱이 실행되는 동안 각 서비스의 페이지가 유지됩니다. 로그인 정보는 각 서비스의 세션에 보관하고, 대화 기록은 서비스에서 관리합니다. Gemini 사용량이나 대화가 Loopline의 Usage·로컬 대화 목록에 자동으로 합쳐지지는 않습니다.

Google은 [내장 브라우저의 OAuth 로그인을 제한](https://developers.google.com/identity/protocols/oauth2/policies#browsers)하며, [Gemini가 지원하는 브라우저](https://support.google.com/gemini/answer/13278668?hl=ko)에 Electron은 포함되어 있지 않습니다. 앱에서 로그인할 수 없거나 호환성 오류가 표시되면 상단의 **브라우저에서 열기**를 사용하세요. 이 경우 브라우저에서 대화를 이어가며, 해당 로그인 세션을 앱으로 복사하지 않습니다. 앱 내부 로그인 및 모든 Gemini 기능의 호환성을 보장하지 않습니다.

## 모델 표시 설정

**모델 선택 → 표시 설정** 또는 **설정 → 모델 표시**에서 목록에 보일 Codex·Claude Code·API 모델을 개별적으로 켜고 끕니다. 모델 또는 연결 이름으로 검색할 수 있고, 모두 표시·모두 숨기기는 현재 검색 결과 전체에 적용됩니다.

표시 설정은 앱 또는 브라우저의 로컬 저장소에 자동으로 저장됩니다. 같은 모델 이름도 API 연결별로 구분하며, 숨겨도 현재 선택한 모델과 기존 대화는 유지됩니다. 모든 모델을 숨긴 경우 선택 목록 아래의 **표시 설정**에서 다시 켤 수 있습니다. 새로 추가된 모델은 기본으로 표시됩니다. 앱 안의 ChatGPT 공식 웹 모델 목록은 해당 서비스의 설정을 따릅니다.

## API 에이전트 연결

1. 사이드바의 **에이전트 +** 또는 **계정 메뉴 → Settings → API 에이전트 → 에이전트 추가**를 엽니다.
2. 에이전트 이름·API 기본 주소·키를 입력합니다.
3. **연결 및 모델 가져오기**를 누르면 `/models`를 조회합니다. 성공한 연결의 모델이 화면 왼쪽 위 **모델 선택** 목록에 바로 나타납니다.
4. 목록에서 모델을 고르고 메시지를 보냅니다. 별도의 서비스 선택 단계는 없습니다. 같은 모델 이름도 연결별로 구분됩니다.

DeepSeek 기본 주소는 `https://api.deepseek.com`, OpenAI는 `https://api.openai.com/v1`입니다. 사용자 지정 서비스는 Bearer API 키, `GET /models`, `POST /chat/completions`와 SSE 스트리밍을 제공하는 OpenAI 호환 API를 지원합니다. 기본 주소에는 `/models`나 `/chat/completions`를 붙이지 않습니다. HTTPS를 사용하며 localhost만 HTTP를 허용합니다. 모델 목록에 포함되어 있어도 일부 모델은 Chat Completions를 지원하지 않을 수 있습니다. 그런 모델은 응답 시 지원 여부를 확인하는 오류가 표시됩니다. API 에이전트는 텍스트 대화와 프로젝트 지침을 지원하며 도구 실행은 제공하지 않습니다.

키는 대화 기록이나 브라우저 `localStorage`에 저장하지 않습니다. 데스크톱에서는 Electron `safeStorage`와 macOS 키체인으로 암호화하여 앱 데이터 폴더의 `api-connections.json`에 저장합니다. 서명되지 않은 로컬 빌드는 업데이트 시 키체인 접근을 다시 요청할 수 있습니다. 웹 개발 서버는 키를 메모리에만 보관하므로 서버 재시작 후 다시 입력해야 합니다. API 사용료는 각 서비스의 API 계정에 청구되며 구독 계정 한도와 별개입니다.

API 연결은 편집·모델 새로고침·연결 해제·삭제가 가능합니다. 연결 해제는 이 앱에서 키를 제거하며 서비스 측 키 자체를 폐기하지 않습니다. 삭제해도 대화 본문은 남고, 다음 응답에는 사용자가 다른 모델을 선택해야 합니다. API 주소를 바꿀 때는 새로운 키를 입력해야 하며, 응답 중인 연결은 편집하거나 삭제할 수 없습니다. API 오류에 대한 자동 재시도나 다른 API 계정으로의 자동 전환은 하지 않습니다.

## MCP 도구 연결

**계정 메뉴 → Settings → MCP 연결 → 연결 추가**에서 로컬 프로그램(stdio) 또는 원격 Streamable HTTP 서버를 등록합니다. 로컬 서버에는 실행 명령과 줄마다 하나의 인자, 필요하면 환경 변수와 작업 폴더를 입력합니다. 원격 서버에는 HTTPS 주소와 선택적 Bearer 토큰을 입력합니다. 저장 후 연결하면 서버가 제공하는 도구 목록을 불러옵니다.

그다음 **Loop 구성 → Loop에서 사용할 MCP 도구**에서 실행에 허용할 도구를 체크합니다. 체크한 도구만 계획·구현·일반 판정 모델의 호출 대상이 됩니다. Jev 판정 연결은 MCP 도구를 직접 호출하지 않습니다. 실제 도구 호출의 AI 모델, 입력, 결과는 Loop 단계 기록을 눌러 확인할 수 있습니다. 한 단계에서 도구를 최대 8회 호출하며, MCP 도구를 실행한 뒤 중지되거나 앱이 닫힌 실행은 같은 도구가 재실행되지 않도록 자동 재개를 막습니다.

데스크톱 앱에서는 인자·환경 변수·토큰을 macOS 보안 저장소로 암호화합니다. 웹 개발 서버는 이 값을 메모리에만 보관하므로 서버가 재시작되면 다시 입력해야 합니다. MCP 서버를 연결하는 순간 로컬 실행 명령이 시작되거나 원격 서버에 접속합니다. 도구는 외부 파일·서비스를 변경할 수 있으므로 Loop에 추가할 도구를 직접 선택하세요. 연결은 사용 중인 MCP 서버의 버전과 권한 정책을 따릅니다.

## 기존 대화 선택 가져오기

1. **계정 메뉴 → Settings → 대화 가져오기 → Codex · Claude Code**를 열고 대화 출처를 선택합니다. Codex는 가져올 로컬 계정도 선택할 수 있습니다.
2. 기본 목록은 앱·IDE 기록을 표시합니다. **CLI 대화 포함**, **출처 불명 포함**을 각각 켜서 필요한 기록만 추가하고, Codex의 보관된 기록도 따로 조회할 수 있습니다. 필터를 바꾸면 기존 선택은 해제됩니다.
3. 제목으로 검색하고 대화 제목을 눌러 본문을 미리 봅니다. 원하는 항목을 체크한 뒤 **선택한 대화 가져오기**를 누릅니다. 프로젝트를 지정하거나 ‘프로젝트 미지정’으로 저장할 수 있습니다.
4. 가져온 대화를 열고 모델 선택기로 Codex·Claude·API 모델 중 원하는 모델을 골라 이어갑니다. 이미 가져온 대화는 중복 저장하지 않습니다.

가져오기는 선택 시점의 사용자·AI 텍스트를 Loopline에 복사하는 방식입니다. 원본 대화와 양방향 동기화하지 않으며, 가져온 대화를 삭제해도 원본 기록은 삭제되지 않습니다. 도구 실행 결과, 내부 추론, 첨부 파일은 가져오지 않습니다. 전체 텍스트는 로컬에 보관하고, 이어지는 응답에는 최근 최대 60개 메시지를 요청 크기 한도 안에서 전달합니다. 문맥을 줄이면 화면에 안내합니다.

Codex는 공식 [app-server의 thread/list·thread/read](https://learn.chatgpt.com/docs/app-server)를 사용하며 서버가 기록한 source와 originator로 출처를 구분합니다. Claude Code는 공식 [로컬 transcript 저장 경로](https://code.claude.com/docs/en/claude-directory)의 `~/.claude/projects/*/*.jsonl`을 읽습니다. `CLAUDE_CONFIG_DIR`가 설정되어 있으면 해당 폴더를 사용합니다. entrypoint가 없는 기록은 ‘출처 불명’으로 분류합니다. 다른 컴퓨터나 클라우드에만 저장된 대화는 이 목록에 나타나지 않습니다. Claude의 클라우드 대화와 ChatGPT 대화는 **계정 메뉴 → Settings → 대화 가져오기 → ChatGPT · Claude**에서 ZIP/JSON을 연 뒤 가져올 대화를 체크하세요. Codex·Claude Code의 대화 선택 창에서도 **내보내기 파일 선택**을 사용할 수 있습니다.

Claude 로컬 파일은 64MB까지 읽으며 목록은 최대 5,000개 파일을 탐색합니다. 읽기 실패와 목록 제한은 화면에 표시합니다. 가져올 텍스트와 기존 저장 데이터가 앱의 로컬 저장 한도를 넘으면 저장하지 않고 선택 개수를 줄이도록 안내합니다.

## 대화 복사와 내보내기

대화 화면 오른쪽 위 **대화 도구** 메뉴에서 마지막 AI 답변을 클립보드에 복사하거나, 현재 대화를 Markdown 파일로 내려받을 수 있습니다. 내보내기에는 대화 제목·연결·모델·프로젝트와 사용자·AI의 텍스트 메시지가 들어갑니다. 진행 중인 답변이 끝난 뒤 사용할 수 있습니다.

## 데스크톱 앱 만들기

macOS Apple Silicon용 `.app`을 빌드하고 실행합니다.

```sh
npm install
npm run desktop:package
open "release/mac-arm64/Loopline.app"
```

개발 중에는 `npm run desktop`으로 앱 창을 실행할 수 있습니다. 앱은 저장된 대화가 재실행 후에도 유지되도록 전용 로컬 포트 `41743`에서 서버를 시작하고, 창을 닫을 때 함께 종료합니다. 별도 인스턴스를 격리해 실행할 때는 `MOSAIC_DESKTOP_PORT=41744 npm run desktop`처럼 포트를 바꿀 수 있습니다. 포트가 달라지면 브라우저 저장소도 분리됩니다. 이 빌드는 로컬 실행용이며 배포용 Apple 서명·공증은 포함하지 않습니다.

## 웹 개발 서버 실행

1. Node.js 20.3 이상을 준비합니다.
2. 사용할 공식 CLI를 설치합니다.

```bash
npm install -g @openai/codex
npm install -g @anthropic-ai/claude-code
```

3. Loopline 웹 개발 서버를 실행합니다.

```bash
npm start
```

4. 브라우저에서 [http://127.0.0.1:4173](http://127.0.0.1:4173)을 열고, **설정 → AI 연결 → AI 추가**에서 원하는 CLI 서비스를 선택해 로그인합니다.

OpenAI 연결은 Codex app-server의 ChatGPT OAuth 흐름을 사용합니다. app-server가 계정 인증과 토큰 갱신을 관리하고, 계정 상태·Codex 한도·사용 가능한 모델을 조회합니다. Claude 연결은 `claude auth login --claudeai`로 Claude 구독 로그인 절차를 시작합니다.

의존성 설치가 필요 없습니다. 서버는 기본적으로 `127.0.0.1`에서만 대기합니다. 외부 네트워크에 공개하려면 별도의 인증·배포 보안 설계가 필요합니다.

## 포함된 기능

- ChatGPT Desktop 스타일의 채팅 화면·접을 수 있는 에이전트 목록·macOS 통합 타이틀바
- 라이트·다크·시스템 테마 선택, 설정 저장 및 앱 전체 색상 적용
- 메인 창 안의 ChatGPT·Gemini 공식 웹, 공통 전환 메뉴, 서비스별 로그인 세션 및 브라우저에서 열기
- 새 설치에서 AI 연결을 자동 등록하지 않으며, Codex·Claude Code·ChatGPT·Gemini·API 에이전트를 각각 추가·삭제
- Codex·Claude·API 모델을 통합한 검색 가능한 모델 선택기
- DeepSeek·OpenAI·사용자 지정 OpenAI 호환 API 에이전트 추가 및 모델 자동 조회
- API 에이전트 편집·모델 새로고침·연결 해제·삭제 및 API 키 암호화 보관
- 응답 스트리밍, 대화 생성·전환·삭제
- Loopline 앱 창의 대화 기록 저장
- Projects 생성·이름 변경·삭제, 대화 배정·이동·해제 및 프로젝트 지침 적용
- ChatGPT·Claude 내보내기 ZIP/JSON에서 프로젝트, 텍스트 지침·자료와 대화 기록 가져오기
- Codex 추론 강도: 입력창 Fast 옆과 모델 선택 메뉴에서 High·XHigh 등 모델이 지원하는 강도를 선택하고 다음 실행에도 유지
- Codex Fast 모드: 직접 선택한 추론 강도를 유지하며 지원되는 Fast 서비스 티어 요청. 자동 선택에서는 Low 우선 적용
- 여러 Codex 계정의 ChatGPT OAuth 로그인, 계정별 모델·남은 사용 한도 조회 및 계정 선택
- 추가 Codex 계정 별칭 입력 및 로그인 이메일 표시
- OAuth 로그인 취소, Codex app-server 로그아웃, 추가 계정 프로필 삭제
- Claude Code 연결 등록 및 앱 항목 삭제 (CLI 로그인은 유지)
- Codex app-server 기반 대화 thread 이어하기와 한도 초과 시 다른 계정으로 재시도
- Codex 대화별 읽기 전용 임시 작업 폴더와 사용자 MCP 서버 차단
- Claude Code CLI 로그인 상태 표시와 계정 오류 안내

Codex 기본 계정은 사용자가 Loopline에 추가한 뒤에만 같은 컴퓨터의 Codex CLI 인증 상태와 thread 기록을 사용합니다. Loopline에서 기본 연결을 삭제해도 Codex CLI 로그인은 유지됩니다. 추가 계정은 macOS의 앱 데이터 폴더 아래 계정별 `CODEX_HOME`으로 격리하며, 인증 파일을 복사하지 않습니다. 각 Codex 계정의 app-server가 제공하는 사용 한도 창의 남은 비율과 재설정 시각을 표시합니다. 사용 한도 초과가 app-server 응답에서 확인되면 남은 한도가 있는 연결 계정에서 같은 대화 내용을 새 thread로 재시도합니다. 인증 실패, 네트워크 오류, 모델 사용 불가 오류는 계정을 바꾸어 재시도하지 않습니다. Claude Code CLI는 로그인 상태를 확인하며, 플랜 사용량은 Claude Code 내부에서 `/usage`를 실행해 확인해야 합니다. Codex app-server의 프로토콜 상태와 호환성은 [공식 문서](https://learn.chatgpt.com/docs/app-server)를 확인해 주세요. Loopline에서 Codex 대화를 삭제하면 해당 계정의 app-server thread 기록도 삭제됩니다.

Projects는 대화와 프로젝트 지침을 앱 창의 `localStorage`에 저장합니다. 사이드바의 아래 화살표에서 ChatGPT 또는 Claude 계정 설정의 데이터 내보내기로 받은 ZIP이나 JSON 파일을 고르면 파일을 이 Mac에서 읽고, 가져오기 전에 서비스와 자료 수를 확인합니다. 가져온 프로젝트 지침과 텍스트 자료는 이후 응답 문맥에 포함되며, 대화는 원본 서비스 ID를 사용해 반복 가져오기에서 중복을 건너뜁니다. 첨부 파일 바이너리는 가져오지 않습니다. 현재 로컬 저장 방식에 맞춰 파일은 256MB, 개별 JSON은 64MB, ZIP 안의 JSON 총량은 128MB 이하로 제한하고, 기존 대화를 포함한 앱 저장 데이터가 약 3.8MB를 넘을 것으로 예상되면 저장하지 않습니다. ChatGPT 내보내기에 원래 Projects 정보가 포함되지 않은 경우 해당 대화는 가져오기 프로젝트로 묶입니다.

입력창 하단에서 세부 모델을 고르고 **Fast 옆 추론 선택기**에서 현재 강도를 보고 High·XHigh 등으로 바로 변경할 수 있습니다. 상단은 연결 선택, 입력창의 모델 메뉴는 세부 모델 선택만 담당합니다. Codex 옵션은 연결 계정의 `model/list.supportedReasoningEfforts`를 따르며, 선택값은 로컬에 저장하고 `turn/start.effort`로 전달합니다. 자동 선택은 모델 기본값을 사용하며 Fast를 켜면 지원되는 경우 Low를 적용합니다. 직접 선택한 강도는 Fast보다 우선합니다. 계정 자동 전환도 선택한 강도를 지원하는 계정에만 허용하며, 저장한 강도가 현재 모델에서 지원되지 않으면 자동 선택을 사용합니다.

**계정 메뉴 → Usage → 토큰 활동 통계**에서 Codex 계정을 선택하면 `account/usage/read`가 제공하는 누적 토큰, 최대 일일 토큰, 최장 실행 시간, 현재·최장 연속 사용일을 조회합니다. 최근 1년의 활동은 일별 히트맵, 주별 합계, 기간 누적 그래프로 전환할 수 있습니다. 누적 그래프는 표시 기간 안의 토큰만 누적하며, 제공되지 않은 지표는 `—`로 표시합니다. 상단 **남은 사용 한도**에서 전체·개별 계정의 한도와 초기화 시간을 볼 수 있습니다.

활동 내역은 선택한 계정의 `CODEX_HOME/sessions`와 `archived_sessions`를 읽기 전용으로 집계합니다. 기본 범위는 앱·IDE이며 **CLI 기록 포함**으로 범위를 넓힐 수 있습니다. 하위 에이전트와 출처 불명 기록은 제외합니다. Fast 비율은 서비스 티어가 기록된 응답, 추론 비율은 강도가 기록된 응답을 기준으로 계산합니다. 스킬은 도구가 `SKILL.md`를 열람한 응답 수, 플러그인은 식별자가 기록된 완료 호출 수를 셉니다. 같은 응답의 스킬 재열람과 복제된 호출은 중복 계산하지 않습니다. 이 통계는 로컬 기록 기준이므로 계정 전체의 클라우드 통계와 일치하지 않을 수 있습니다. 파일 5,000개·읽기 4GB·30초·개별 항목 2MB 한도를 넘거나 읽기 오류가 있으면 화면에 부분 집계를 안내합니다. 통계는 Usage 진입과 새로고침에서 조회하며, 대화 본문은 통계 응답에 포함하지 않습니다.

Codex Fast 토글은 모델 목록에서 Fast 서비스 티어를 제공한다고 알리는 경우에만 그 티어를 요청합니다. 티어 정보가 없는 모델은 자동 또는 Low 선택에서만 Fast를 사용할 수 있습니다. 이 앱은 서버가 실제로 처리한 속도 티어의 별도 확인 신호를 제공하지 않습니다. Claude에서는 추론 강도 선택과 Fast 토글을 사용하지 않습니다. 프로젝트를 삭제해도 해당 대화는 보존되고 ‘모든 작업’으로 이동합니다. Codex 연결 해제는 app-server의 `account/logout`을 사용하며, 기본 계정은 `~/.codex`를 공유하므로 Codex CLI에서도 로그아웃됩니다. 추가 계정을 삭제하면 해당 `CODEX_HOME`의 인증 정보와 Codex 세션 기록이 제거됩니다. Loopline 대화 본문은 남고 다음 응답은 다른 계정에 대화 내용으로 이어집니다. Claude Code는 설정의 ‘연결 추가’에서 앱에 등록한 경우에만 모델 선택에 나타납니다. Claude 연결 항목을 삭제해도 Loopline 등록만 지워지고 Claude Code CLI 로그인은 유지됩니다. 진행 중인 Codex 응답은 계정 삭제나 연결 해제를 막습니다.

## 앱 이름과 아이콘

Loopline은 기존 Mosaic Desk의 새 표시 이름입니다. 기존 대화·계정·암호화된 API 키를 유지하기 위해 앱의 내부 저장 이름, 번들 ID, 로컬 저장 키는 기존 값을 사용합니다. macOS 데이터 경로는 `~/Library/Application Support/Mosaic Desk`입니다.

앱 아이콘의 원본은 `public/loopline-icon.svg`, 화면 아이콘은 `public/icons.svg`입니다. macOS 패키지는 `desktop/assets/loopline.icns`를 사용하며, `desktop/assets/loopline-icon.png`는 Dock과 앱 정보 창에 표시됩니다.
