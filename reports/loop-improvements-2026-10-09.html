남은 문제

입력 제약과 내부 QA의 충돌

자체 브라우저 QA 62/66 통과. 제목 101자·과목 31자 입력 뒤 오류를 기대했지만, 화면의 maxlength 100·30이 입력을 제한했습니다. 실패 4건은 실행 중 자동 해소되지 않았습니다.

실측 후 수정

README 검증 실행 경로

Electron 실행 파일을 Node로 사용하던 오류를 수정했습니다. 최종 패키지에서 같은 생성 코드로 3/3 재검사를 통과했습니다. 해당 실행의 자동 완료 수치는 0/1로 유지합니다.

생성 프로젝트 Node 테스트: PASS · 22/22

각 실행 내부에서 수동 코드 수정은 0회, 수동 재개 API 호출은 0회입니다. 개입 0회는 자동 성공을 뜻하지 않습니다. 미완료 산출물을 사람이 완성하는 데 필요한 공수는 측정하지 않았습니다. 구성별 1회이므로 장기 성공률이나 모든 작업에서의 우위를 추정할 수 없습니다.

실측 후 원인 확인

  • 내부 QA는 제목 101자·과목 31자 입력 후 오류 메시지를 기대했습니다. 화면은 maxlength 100·30으로 제한하며, 추가 화면 확인에서도 101자 입력의 실제 값은 100자였습니다. 공통 독립 QA 50/50 통과가 내부 실패를 대신하지 않습니다.
  • README 검증에서는 Electron 하위 프로세스의 process.execPath를 Node 실행 파일로 가정한 것이 원인이었습니다. README의 node 명령을 기존 격리 환경에서 실행하도록 수정했고, 최종 패키지에서 재검사 3/3를 통과했습니다. 생성 코드 수정·AI 재호출은 없었습니다. 추가 검사 원본
  • 첫 구현까지 17분 25.5초, 준비 토큰 618,054이 들었습니다. 변경되지 않은 사례의 재판정 재사용은 동작했지만, QA 의미·경계 조건과 부분 작업 계획 판정에서 추가 호출이 발생했습니다.
  • README 오류 수정 후 새 모델 실행은 하지 않았습니다. 실제 기록의 자동 반영 0/1을 유지하고 기존 6회차 한도도 늘리지 않았습니다.

측정 조건과 해석 시 주의 사항예산 · 계측 · 평가 범위
  • 기본 예산은 전체 200만 토큰·모델 호출 시간 60분, 준비 50만 토큰·15분입니다. 확장·절약은 설정에서 선택합니다. 모델 시간은 전체 벽시계 시간과 다릅니다.
  • 토큰은 응답 후 집계하므로 한 호출만큼 예산을 넘을 수 있습니다. 미보고 토큰을 0으로 확정하지 않고 시간 한도를 함께 적용합니다.
  • 예산 도달은 자동 완료가 아닙니다. 작업 공간·체크포인트는 보존하되 예산을 무한 증액하지 않습니다. 기존 예산 소진 실행의 원클릭 증액·재개는 이번 범위에 포함되지 않았습니다.
  • 기존 기록에 없는 상세 계측은 추정하거나 소급 보정하지 않았습니다. 실패 분류는 관찰한 오류·실행 단계에 근거하며 모든 실패 원인을 확정하는 진단기는 아닙니다.
  • 이전과 동일하게 MCP·native plugin을 비활성화했습니다. Paper/Figma 연결, 휴대폰·Tailscale 왕복 성능을 평가한 결과가 아닙니다.
  • 구조화 스키마는 응답 형식을 안정화합니다. 구현·QA 기준·테스트 성공은 실제 검증으로 따로 확인합니다.
