계정 및 연결

Codex app-server가 ChatGPT OAuth 로그인과 계정별 토큰 저장·갱신을 관리합니다. Claude는 공식 Claude Code CLI 로그인을 사용합니다. Mosaic에 비밀번호나 API 키를 입력하지 않습니다.

연결 해제는 Mosaic 앱 안에서만 해당 계정을 숨깁니다. Codex CLI 인증, CODEX_HOME, OAuth 토큰과 Codex 기록은 로그아웃하거나 삭제하지 않습니다.

Codex 계정계정별 로그인과 사용 한도를 관리합니다.
