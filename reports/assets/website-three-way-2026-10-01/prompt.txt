한국어 사용자용 오프라인 작업 관리 웹사이트 `오늘의 작업`을 이 빈 프로젝트에 완성해 주세요. 설치나 네트워크 없이 HTML/CSS/바닐라 JavaScript와 Node.js 20+ 내장 기능만 사용합니다. 실제 파일, 동작, 테스트, README까지 완성해 검증과 최종 판정 및 자동 반영까지 진행하세요.

기능 및 접근성 요구사항:
1. 루트 index.html에서 실행하며 제목 `오늘의 작업`, 오늘 날짜, 전체·남은·완료 작업 수 및 진행률을 표시합니다. 초기 데이터는 빈 상태이며 데모 데이터를 삽입하지 않습니다.
2. 새 작업 입력은 aria-label="새 작업", 검색 입력은 aria-label="작업 검색"이며 추가 버튼은 `추가`입니다. 공백만 있는 입력은 저장하지 않고 접근성 있는 화면 안내를 표시합니다. 앞뒤 공백은 정리하고 Enter로도 추가할 수 있어야 합니다.
3. 목록의 각 작업은 listitem 의미를 가지며 제목과 완료/완료 취소 및 삭제 버튼을 표시합니다. 각 버튼의 접근성 이름에는 대상 작업 제목과 `완료 처리` 또는 `완료 취소` 또는 `삭제`가 포함됩니다. 제목 중복도 별개의 작업으로 처리하고 한 작업만 삭제할 수 있어야 합니다.
4. `전체`, `할 일`, `완료` 필터 버튼에 aria-pressed로 선택 상태를 표시합니다. 검색은 제목 기준 즉시 반영하며 필터와 동시에 적용됩니다. 검색과 필터 변경도 라이브 영역으로 알립니다.
5. localStorage에 작업과 완료 상태를 저장해 새로고침 후 복원합니다. 작업이 없는 상태와 검색 결과가 없는 상태를 구분해서 안내합니다. 제목은 HTML로 실행하지 않고 문자로 표시합니다.
6. 주요 동작 후 결과는 role="status" aria-live="polite" 영역으로 알립니다. 키보드만으로 추가, 필터, 완료, 삭제가 가능하고 focus-visible 표시가 분명해야 합니다.
7. 390×844 모바일부터 1440×900 데스크톱까지 가로 넘침이 없어야 합니다. 매우 긴 작업 제목도 입력·버튼·카드 배치를 깨뜨리지 않습니다.

시각 설계:
- 생산성 도구답게 여백과 타이포 계층을 정돈하고 밝은 뉴트럴 배경, 짙은 글자, 보라색 포인트를 사용합니다.
- 넓은 화면에는 간결한 내비게이션 영역과 본문, 요약 카드, 진행률, 검색/추가/목록이 명확히 구분되게 구성합니다. 모바일에는 위에서 아래로 읽을 수 있는 배치로 전환합니다.
- 빈 상태, 검색 결과 없음, 완료된 항목, 키보드 포커스도 실제 제품 화면으로 디자인합니다. 외부 이미지/폰트/CDN 없이 CSS와 필요 시 직접 작성한 SVG만 사용합니다.
