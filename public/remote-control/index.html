사용 방법

  1. Mac에서 Tailscale을 연결하고, 폰도 같은 Tailnet에 연결합니다.
  2. 이 페이지에서 원격 접속을 켭니다. 현재 사용 중인 Tailscale 사이트의 다른 경로는 유지됩니다.
  3. 표시된 보안 주소를 폰 Safari에서 열고, 공유 메뉴에서 홈 화면에 추가합니다.

폰에서는 계정 대시보드나 MCP 설정에 접근하지 않습니다. Loop는 새 격리 프로젝트에서 실행됩니다. 검증 명령은 작업 공간의 제한된 샌드박스에서 자동 실행되며, 폰에서 임의 명령이나 MCP 도구를 직접 호출할 수 없습니다.
