  • 기본 실행 예산은 전체 200만 토큰·모델 호출 시간 60분, 준비 단계 50만 토큰·15분입니다. 확장과 절약을 설정 화면에서 선택할 수 있습니다. 모델 시간은 전체 벽시계 시간과 다릅니다.
  • 토큰 수는 응답 후 집계하므로 한 호출만큼 예산을 넘을 수 있습니다. 미보고 토큰을 0으로 확정하지 않으며 시간 한도를 함께 사용합니다.
  • 예산 도달은 자동 완료가 아닙니다. 작업 공간과 체크포인트를 보존하지만 예산을 자동으로 무한 증액하지 않습니다. 기존 예산 소진 실행의 원클릭 증액·재개는 이번 범위에 포함되지 않았습니다.
  • 기존 기록은 세부 계측이 없으므로 새 값으로 추정하거나 소급 보정하지 않습니다. 새 실패 분류는 관찰 가능한 오류·실행 단계에 근거하며 모든 실패의 원인을 확정하는 진단기는 아닙니다.
  • 이번 실측은 이전과 동일하게 MCP와 native plugin을 비활성화했습니다. Paper/Figma 연결이나 휴대폰·Tailscale 왕복 성능을 평가한 결과는 아닙니다.
  • 구조화 스키마는 형식을 안정화하는 수단입니다. 올바른 구현·QA 기준·테스트 성공은 실제 검증으로 따로 확인합니다.

Codex의 turn별 outputSchema는 공식 App Server 문서를 확인해 적용했고, 엄격한 JSON 구조는 공식 Structured Outputs 문서의 형식 제한에 맞췄습니다.
