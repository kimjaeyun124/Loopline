이 Mac의 Codex 기록 기준

자주 사용한 스킬·플러그인

Fast와 추론 비율은 설정이 기록된 응답 기준입니다. 스킬은 응답별 열람 횟수, 플러그인은 기록된 호출 횟수를 집계합니다. 계정 전체 통계와 범위가 다를 수 있습니다.

모델 표시

모델 선택 목록에 표시할 모델을 켜 주세요.

변경 사항은 자동으로 저장됩니다. 숨겨도 현재 사용 중인 모델과 기존 대화는 유지됩니다. 새로 추가된 모델은 기본으로 표시됩니다.
