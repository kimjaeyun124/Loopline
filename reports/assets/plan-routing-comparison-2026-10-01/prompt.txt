한국어 오프라인 작업 관리 웹사이트 ‘Focus Desk’를 빈 프로젝트에 완성하세요. HTML/CSS/바닐라 JavaScript, Node.js 20+ 내장 기능만 사용하며 외부 패키지·설치·CDN·네트워크 요청 없이 동작해야 합니다. 실제 파일, 기능 테스트, README를 만들고 검증·최종 판정·자동 반영까지 끝내세요.

작업 계획은 저장/기능 로직과 화면/통합의 검증 가능한 두 부분으로 나누세요. 먼저 저장과 작업 조작을 단독 검사하고, 다음에 화면을 연결하고 전체 검증하세요. 담당 파일과 완료 기준을 명확히 하고 미완료 작업만 수정하세요.

기능 요구사항:
1. 루트 index.html에서 실행합니다. 첫 시작은 빈 목록이며 데모 데이터를 자동 삽입하지 않습니다. 제목 Focus Desk, 전체·남은·완료 개수, 진행률을 보여줍니다.
2. 입력의 접근성 이름은 ‘새 작업’, 검색 입력은 ‘작업 검색’, 추가 버튼은 ‘추가’입니다. 공백만 있는 제목은 거부하고 안내합니다. 앞뒤 공백을 정리하며 버튼과 Enter 모두로 추가합니다.
3. 각 작업은 listitem 의미와 제목을 가지며 완료 처리/완료 취소 및 삭제 버튼을 제공합니다. 버튼 접근성 이름은 대상 제목과 ‘완료 처리’, ‘완료 취소’, ‘삭제’를 포함합니다. 중복 제목의 작업은 독립적입니다.
4. ‘전체’, ‘할 일’, ‘완료’ 버튼으로 필터링하며 aria-pressed로 선택 상태를 표시합니다. 제목 검색은 즉시 반영되고 필터와 함께 적용됩니다. 저장된 항목이 없을 때와 검색 결과가 없을 때의 안내는 구분합니다.
5. 목록과 완료 상태를 localStorage에 저장해 새로고침 후 복원합니다. HTML처럼 생긴 제목은 문자로 표시합니다. 동작 결과는 role="status" aria-live="polite" 영역으로 알립니다. 키보드로 입력·추가·필터·완료·삭제가 가능하며 focus-visible 표시를 제공합니다.
6. 1440×900 데스크톱과 390×844 모바일에서 가로 넘침이 없어야 합니다. 매우 긴 제목도 카드와 버튼 배치를 깨뜨리지 않습니다.

디자인: 밝은 따뜻한 뉴트럴 배경, 짙은 네이비 글자, 코발트 블루 포인트. 넓은 화면은 간결한 좌측 내비게이션과 본문, 요약 카드, 진행률, 추가/검색/목록을 정돈합니다. 모바일은 단일 열로 바꿉니다. 여백·타입·카드·빈 상태·완료 상태·포커스에 일관된 시각 위계를 적용합니다. 외부 이미지/폰트를 사용하지 않습니다.

검증: package.json에 npm test를 구성하고 Node 내장 테스트로 추가, 공백 거부, 제목 정리, 완료/취소, 중복 제목의 독립 삭제, 검색과 필터, 저장 복원을 검사합니다. 파일 존재만 확인하는 검사를 완료 근거로 사용하지 마세요. 독립 브라우저 QA에서 실제 입력·새로고침 저장·빈 상태·키보드·반응형 화면을 검사하고 실패하면 근거를 반영해 자동 수정한 뒤 통과해야 자동 반영하세요.
