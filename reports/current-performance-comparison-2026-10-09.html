실행 결과

이번 결과의 해석

현재 가장 큰 병목은 완료 흐름의 신뢰성입니다. Luna와 Sol은 독립 QA 계획 보완 중 종료되어 구현 모델이 한 번도 호출되지 않았습니다. 자동 Loop는 화면까지 만들었으나 부분 작업의 판정 기준과 실제 QA 실행 시점이 충돌해 같은 UI 작업을 다섯 번 시도한 뒤 6회차 한도에 도달했습니다. 어느 구성도 자체 브라우저 QA·README QA·최종 통합 검증 단계에 도달하지 못했습니다.

자동 Loop의 계획·판정이 보고 토큰의 70.6%를 사용했습니다. 계획 233,732토큰, 판정 615,504토큰, 구현 353,571토큰입니다. 첫 구현 호출 전 약 16분 40초 동안 384,401토큰을 사용했습니다. 먼저 근거 충돌과 반복 계획 보완을 줄여야 구현·최종 QA에 자원을 쓸 수 있습니다. 모델 호출 경로의 대기 시간 합은 전체 시간의 약 99.9%이며, 이 값에는 CLI·중계 경로 시간이 포함됩니다.

자동 Loop의 실행 시간은 Luna의 8.13배, Sol의 2.91배이고 보고 토큰은 각각 6.82배와 3.96배입니다. 다만 고정 구성은 코드를 만들기 전에 실패했으므로 이 비율을 성공한 프로그램 제작의 효율 차이로 해석할 수 없습니다. 이번 실험에서는 Loop의 비용·시간 우위를 입증하지 못했습니다.

Luna가 중단된 원인

초기 QA 계획은 허용되지 않는 notApplicable.malformed-storage 분류를 통과시켰지만 보완 경로는 같은 값을 거부했습니다. 모델의 재요청은 이미 검사 중인 save를 해당 없음으로 바꾸려다 실패했습니다. 초기와 보완 스키마가 일치하지 않는 문제가 순수 함수 재현에서도 확인됐습니다.

Sol이 중단된 원인

검색 QA 입력에 줄바꿈과 사용자: 문자열이 섞여 기대 결과와 모순됐습니다. 판정은 검색어를 문법으로 고치라는 구체적인 사유를 냈지만 모델이 실제 변경 없는 보완 응답을 두 번 반환해 종료됐습니다. 코드 구현 품질은 이번 실행에서 평가하지 못했습니다.

세 구성 모두 수동 코드 수정·수동 재시작·관찰 한도에 의한 중지는 0회였습니다. 이는 사람 없이 성공했다는 뜻이 아닙니다. 미완료 결과를 사람이 완성하는 데 필요한 공수는 미측정입니다. 생성 프로젝트를 수동으로 고쳐 성공 결과로 바꾸지 않았습니다.

현재 완료율·브라우저 QA·시간·토큰·개입 기록과 최소 표본 판단은 이미 있습니다. 여기에 모델 출력 결함과 Harness의 단계별 근거 충돌을 구분하고, 제공자가 보고하는 입력·출력·캐시 토큰 및 첫 응답 시간을 실행 이벤트와 연결하는 것이 다음 보완입니다. 플랫폼 흐름 때문에 막힌 결과를 모델의 코드 품질 문제로 단정하지 않습니다.		기존 model evidence 집계, 호출 어댑터와 추천 화면. 누락된 값은 미확인으로 유지하고 현재 기록을 확장.역할별 최소 3개 이상의 독립 과제 표본. 실패/시간 초과의 미보고 토큰은 0으로 처리하지 않음. 근거 충돌을 보완한 뒤 모델 조합 다시 비교.

위 내용은 이번 실측에서 나온 보완 제안입니다. 이번 작업은 측정·보고서 작성이며 제품의 모델 선택이나 저장·복구 로직을 변경하지 않았습니다. 개선 폭은 해당 변경을 적용한 뒤 같은 계약으로 다시 측정해야 합니다.

해석 범위와 재현 자료

  • 각 구성 1회, 한 가지 프로젝트 결과입니다. 장기 성공률이나 모든 작업에서 우수한 모델을 추정할 수 없습니다.
  • 같은 Harness의 모델 구성 비교입니다. 독립 Codex 단일 채팅과의 비교로 확대하지 않습니다.
  • 제공자가 보고한 토큰 합계를 사용합니다. 호출별 토큰을 보고하지 않은 경우 합계는 하한이며, 구독 사용률을 토큰 또는 달러 비용으로 변환하지 않습니다. 서로 다른 제공자의 토큰은 동일 과금 단위가 아닙니다.
  • 공통 브라우저 QA는 동작과 가로 넘침을 평가합니다. 미적 품질, 전체 WCAG 준수, 실제 iPhone/Tailscale 왕복 지연은 별도 평가가 필요합니다.
  • 이번에는 45분 관찰 한도에 의한 중지가 없었습니다. 자동 Loop는 설정한 6회차 한도로 종료됐습니다. 생성 파일을 수동 보정해 통과시키지 않았습니다.
  • 실험용 수집 스크립트·브라우저 실행기 작성과 기동 조정은 공통 시험 준비 작업입니다. 이를 생성 프로그램에 대한 사람의 코드 수정으로 계수하지 않습니다. 미완료 프로젝트를 완성하는 데 필요한 실제 사람 시간은 별도로 측정하지 않았습니다.
