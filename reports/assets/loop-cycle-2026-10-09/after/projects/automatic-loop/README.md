# Focus Board

한국어 학습 작업 관리 웹앱입니다. Node.js 20 이상과 브라우저 표준 API를 사용하며 외부 라이브러리나 네트워크 호출이 필요하지 않습니다.

## 실행

프로젝트 루트에서 실행합니다.

```sh
node server.mjs
```

브라우저에서 기본 주소를 엽니다.

```text
http://127.0.0.1:3000/
```

다른 포트를 사용하려면 `PORT` 환경 변수를 지정합니다.

```sh
PORT=4321 node server.mjs
```

## 테스트

프로젝트 루트에서 전체 테스트를 실행합니다.

```sh
node --test
```

작업 데이터는 브라우저의 `localStorage`에 저장됩니다.
